## Lesson

A whole class of bug the data-currency review was never designed to find turned up because one reviewer actually
typed into the calculator. Six rounds in, the automated runtime check (change one input, see if output changes)
reported these pages as "reactive": setting a value programmatically works, typing does not. The runtime script
should type character by character and check the field value.
