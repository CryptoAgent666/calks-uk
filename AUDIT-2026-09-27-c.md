## Lesson

Five rounds, 100 pages: every round found wrong calculations on at least half the sample, and the ledger was
usually right where the code or prose was wrong. The cheapest high-yield check is still the one the automated
audit cannot do: run the default and one edge input through `calculate()` and compare with the law.
